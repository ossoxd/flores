Esta carpeta contiene la copia descargada y autorizada del pack. El juego utiliza directamente, sin modificar sus píxeles:

- `carrot island - free pack/summer tileset.png`
- `carrot island - free pack/carrot island - free pack/character/bunnyidle.png`
