# Retratos RPG

`girl-portraits.js` contiene la hoja PNG aportada por el usuario (seis expresiones), normalizada en celdas de 256 px con margen. `rabbit-portraits.js` contiene cuatro expresiones creadas con la herramienta integrada de generación de imágenes, usando como referencia el conejo original de Carrot Island. Se conserva el PNG como data URI para que los nuevos assets viajen con el proyecto sin depender de rutas temporales ni del instalador.

Orden de ella: confundida, desconcertada, feliz, enojada, muy feliz, neutral. Orden del conejo: feliz, contento, molesto, cool.

Prompt del conejo: atlas regular 2×2 de retratos RPG pixel art, mismo conejo rosa/lila y overol azul del sprite original; cabeza y orejas completas, expresiones feliz, contento, molesto y guiño confiado; fondo transparente, sin texto y encuadre consistente.

La hoja de caminar `../girlfriend/girlfriend-walk-v3.js` se creó con la herramienta integrada tomando la anterior como referencia. Prompt: conservar identidad, cabello y ropa; ciclo 4×4 frente/izquierda/derecha/espalda, contacto de una pierna, paso con pies juntos, contacto opuesto y paso; brazos a contratiempo, cuerpo completo, margen transparente y línea de pies consistente. La normalización conserva el rectángulo alfa entero, sin máscaras de otras poses.
